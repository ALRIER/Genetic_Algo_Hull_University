# Phase 1 Discovery Results (N_EST = 10)

This folder contains the summarized outputs from the initial regime-first genetic-algorithm discovery stage.

## Main files

- `REGIME_FIRST_THESIS_RESULTS_COMPACT__ALL_SEEDS.csv`: compact candidate-level results across seeds.
- `REGIME_FIRST__ALL_FAMILIES_SUMMARY__ALL_SEEDS.csv`: family-level summary across seeds.
- `REGIME_FIRST_SEED_STABILITY_SUMMARY.csv`: stability of selected results across discovery seeds.
- `MULTISEED_METHOD_AUDIT_SUMMARY.csv`: multi-seed methodological checks.
- `REGIME_FIRST_METHOD_AUDIT_SUMMARY__ALL_SEEDS.csv`: detailed method-audit summary.
- `REGIME_FIRST_PROFILE_MATCHED_AUDIT__ALL_FAMILIES__ALL_SEEDS.csv`: profile-matched audit results.
- `REGIME_INTERFAMILY_PROFILE_MATCHED_AUDIT__ALL_FAMILIES__ALL_SEEDS.csv`: cross-family profile-matched audit results.
- `distributional_diagnostics/`: density plots, Q-Q plots, moments, tests, and shape summaries used to verify the simulated families.

Historical output filenames are retained where changing them would break traceability to the recorded experiment.
