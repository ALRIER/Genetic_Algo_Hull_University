# Evidence Taxonomy Results (N_EST = 26)

This folder classifies Phase 2 candidates according to the strength and scope of the fixed-weight validation evidence.

## Main tables

- `tables/evidence_taxonomy_all_candidates.csv`: complete candidate taxonomy.
- `tables/validated_specialists.csv`: candidates supported as validated specialists.
- `tables/discovery_supported_local_candidates_not_fixed_weight_confirmed.csv`: discovery-supported candidates that were not confirmed by fixed-weight validation.
- `tables/near_gate_candidates_not_fixed_weight_confirmed.csv`: near-gate candidates that were not confirmed by fixed-weight validation.
- `tables/evidence_grade_counts.csv`: counts by evidence grade.
- `tables/evidence_grade_by_family.csv`: evidence-grade distribution by family.

## Supporting evidence

`support/` contains the bootstrap confidence-interval, regime-stability, and seed-level gate tables used to construct the taxonomy.

The taxonomy preserves the distinction between discovery evidence, fixed-weight validation evidence, and benchmark-retained cases.
